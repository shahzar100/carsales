## Accessibility

### WCAG Level: AA

### Checklist for New Components

- [ ] Color contrast: 4.5:1 for normal text, 3:1 for large text (18px+ bold or 24px+)
- [ ] Focus indicators: `focus:border-red-500 focus:ring-2 focus:ring-red-100 focus:outline-none`
- [ ] All interactive elements are keyboard-focusable
- [ ] Images have descriptive `alt` text
- [ ] Icon-only buttons have `aria-label`
- [ ] Decorative icons have `sr-only` screen reader text
- [ ] Form errors: `aria-invalid` on field, `aria-describedby` linking to error message
- [ ] Use semantic HTML: `nav`, `main`, `header`, `footer`, `section`, `article`
- [ ] Toggles: `role="switch"` + `aria-checked`
- [ ] Dropdowns: `aria-haspopup="listbox"` + `aria-expanded`
- [ ] Modals: `role="dialog"` + `aria-modal="true"` + `aria-labelledby`

### ARIA Patterns

```tsx
// Icon-only button
<button aria-label="Delete item">
  <Trash2 size={20} />
</button>

// Form error
<input aria-invalid={!!error} aria-describedby="email-error" />
{error && <p id="email-error" className="text-sm text-red-600">{error}</p>}

// Toggle switch
<button role="switch" aria-checked={checked} onClick={() => toggle()}>

// Dropdown
<button aria-haspopup="listbox" aria-expanded={isOpen}>
<ul role="listbox">
  <li role="option" aria-selected={isSelected}>
```

## Responsive Design

### Mobile-First Approach

All components use mobile-first responsive design. Base styles target mobile, then scale up:

```tsx
// Grid: 1 col mobile -> 2 col tablet -> 3 col laptop -> 4 col desktop
"grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4"

// Page padding
"px-4 sm:px-6 lg:px-8"

// Navigation
// Mobile: hamburger menu (xl:hidden)
// Desktop: horizontal nav (hidden xl:flex)
```

### Touch Targets

- Social media icons: 44x44px (`h-11 w-11`)
- Navigation buttons: minimum 40x40px
- Form inputs: minimum 44px height with padding
